# Gulnar Store

A desktop store application developed using Java and JavaFX. It helps manage store operations through a graphical user interface (GUI).

## How to Run

1. Download the project: click **Code** then **Download ZIP**, then extract it.
2. Open the extracted folder in IntelliJ IDEA (**File > Open**).
3. Wait for Maven to load the dependencies.
4. Run the `Project` class.

## Login

The program reads the login data from a file (`USERS.txt`).
To log in, you must enter a **username and password that exist in this file**.
If the username or password is not in the file, the login will fail.

## Data Files

The program reads its data from these text files (located in the project folder):

- `Products.txt`
- `Categories.txt`
- `USERS.txt`
